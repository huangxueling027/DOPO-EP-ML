# Publication-quality image export update (2026-09-20)

This patch addresses low-resolution manuscript/SI images without changing the
underlying data, figure content, layout logic, or colour palette.

## What changed

1. `paper_utils.save_figure()` now explicitly exports every Python-generated
   figure as:
   - **PDF**: vector, preferred for journal submission;
   - **PNG**: high-resolution raster, for Word/WPS insertion;
   - **SVG**: vector backup/editable source.
2. Raster export now respects the command-line `--dpi` value while enforcing a
   minimum of 600 dpi. The default remains **900 dpi**.
3. `make_paper_figures.py` and `run_all_paper_outputs.py` now pass `--dpi`
   through to both main and supplementary figure generators.
4. `audit_figure_resolution.py` was added. It records pixel size and effective
   DPI at 190-mm full-width and 90-mm single-column placement.
5. `run_all_paper_outputs.py` automatically writes
   `results/09_PaperFigures/figure_resolution_audit.csv` unless
   `--skip-resolution-audit` is used.

## Recommended commands

From the **project root** (`ML_DOPO_Project`), run:

```bash
D:/Anaconda/python.exe -u 09_PaperFigures/run_all_paper_outputs.py --dpi 900
```

If you only want to regenerate figures, not tables/audit inputs:

```bash
D:/Anaconda/python.exe -u 09_PaperFigures/make_paper_figures.py --dpi 900
D:/Anaconda/python.exe -u 09_PaperFigures/audit_figure_resolution.py \
  --figures-root results/09_PaperFigures \
  --report results/09_PaperFigures/figure_resolution_audit.csv
```

Or regenerate separately:

```bash
D:/Anaconda/python.exe -u 09_PaperFigures/make_main_figures.py \
  --results-root results \
  --output results/09_PaperFigures/main \
  --dpi 900

D:/Anaconda/python.exe -u 09_PaperFigures/make_supplementary_figures.py \
  --results-root results \
  --output results/09_PaperFigures/supplementary \
  --dpi 900
```

## Which files to use

- **Submission to Elsevier:** use the generated `.pdf` figure files whenever
  the submission system accepts them.
- **Insert into Word/WPS:** use the matching `.png` files generated in the same
  run. Do not use screenshots or old 800×800 PNGs.
- In Word: `File -> Options -> Advanced -> Image Size and Quality -> Do not
  compress images in file` and select `High fidelity`.

## Important

`Fig. 1` and the Graphical Abstract are not generated by this Python folder if
they are manually composed illustrations. Re-export those separately from the
editable source as PDF plus a 3000–4000 px wide PNG. Do not upscale an old
low-resolution PNG as the final source.
